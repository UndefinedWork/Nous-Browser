# 快捷键核对

本轮参考 [Chrome Mac](https://support.google.com/chrome/answer/157179?hl=en) 与 [Safari Mac](https://support.apple.com/guide/safari/cpsh003/mac) 的常用约定。

| 本轮补齐 | 操作 |
| --- | --- |
| ⌘⇧R | 强制刷新网页资源，保留登录状态和网站本地存储 |
| ⌘F | 打开网页查找，重复按下会聚焦并全选查询词 |
| ⌘G / ⌘⇧G | 下一个／上一个匹配；查找框中 Return / ⇧Return 也可使用 |
| ⌘+（或 ⌘=）/ ⌘- / ⌘0 | 放大／缩小／恢复 100%，仅调整当前标签页 |
| ⌘1–8 / ⌘9 | 按当前列表顺序选择标签页／选择最后一个标签页 |
| Control-Tab / Control-⇧Tab | 下一个／上一个标签页，支持首尾循环 |
| ⌘⌥→ / ⌘⌥← | 下一个／上一个标签页的另一组快捷键 |

原有的 ⌘N、⌘T、⌘W、⌘⇧W、⌘⇧T、⌘L、⌘R、⌘⇧[ / ] 和前进后退继续保留。查找和地址输入框中的 ⌘←／⌘→ 保留文本移动行为。剪切、复制、粘贴、全选、撤销／重做及退出、最小化沿用 macOS 菜单。

1.1.6（Build 46）将两种侧边栏操作分开，视图菜单中的名称随当前窗口状态变化：

| 快捷键 | 操作 |
| --- | --- |
| ⌘/ | 展开侧边栏／收窄为图标竖条；完全隐藏时直接展开 |
| ⌘. | 完全隐藏侧边栏／恢复隐藏前的展开或图标竖条状态 |
| Esc | 关闭地址／查找浮层；没有浮层时停止加载 |

⌘. 不再用于停止加载。停止加载仍可通过导航菜单和页面加载时的停止按钮操作；侧边栏的完全隐藏状态不会覆盖上一次的展开宽度或图标竖条状态。

原生菜单核对确认：文件菜单目前没有打开文件（⌘O）、打印（⌘P）、保存网页（⌘S）入口；当前也没有独立书签、历史／下载管理页面或隐私窗口。相关快捷键需要与对应功能一起实现，本轮未添加空操作。视图菜单已有系统全屏入口。

强制刷新使用 WebKit 的源站重验证能力，不会删除 Cookie、Local Storage 或主动注销账号。它不等同于清除全部网站数据，也不保证移除网站自行管理的离线资源。
