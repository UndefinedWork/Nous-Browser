# 1.0.5 验证记录

版本：1.0.5（Build 34），Apple Silicon。

- 按 [Figma 选中标签设计](https://www.figma.com/design/ecisQPouXoxDJd9ZjOVLjH/Pico?node-id=373-423) 添加 0.5pt、黑色 6% 透明度的胶囊内描边；深色模式使用同等透明度的白色描边。
- 描边由选中状态独立控制；使用不接收点击、不进入辅助功能树的 overlay，保持原行高、内边距和鼠标操作区域。
- 原生界面核对浅色与深色显示，点击第二个标签及 Control-Tab 切到第三个标签后选中状态正确。只有当前项显示描边，选中切换沿用 Spring，并尊重系统减少动态效果设置。
- Debug 与 Release 构建通过；DMG/ZIP 的 1.0.5（34）版本、实际 arm64 架构、严格签名、包内容及 SHA256 校验通过。
- 已安装到 `/Applications/Nous Browser.app` 并启动，运行文件与发布构建一致；升级前正常退出并备份，原有 2 个窗口共 16 个标签的身份、顺序、置顶、选中状态及侧边栏布局保持一致。

本轮是选中态的视觉调整，以设计参数核对、构建和原生视觉验收为验证范围，未重复运行与本次改动无关的完整浏览器或密码填写测试。上一版本的行为验证见 [1.0.4 验证记录](QA-1.0.4.md)。应用继续使用未公证的 ad-hoc 签名。
