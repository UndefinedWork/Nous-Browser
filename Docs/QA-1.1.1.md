# 1.1.1 动态 favicon 验证记录

版本：1.1.1（Build 41），Apple Silicon，macOS 26.0+。

## 修复范围

- 原实现只在页面加载完成时发现图标，容易漏掉文档应用稍后设置的 favicon。现在观察主文档 head 中图标声明的新增、修改、移除，以及媒体条件和单页应用地址变化。
- 使用网站声明的 `rel=icon`，支持普通图片、SVG／emoji、data 和同源 blob 图标。适用条件相当时采用较后的声明，失败后再尝试其他候选；没有文档图标时才回退到站点图标。选择原则参考 [HTML 标准 rel=icon](https://html.spec.whatwg.org/multipage/links.html#rel-icon)。
- 每个页面独立缓存图标，包含片段路由；仅站点根路径 `/favicon.ico` 可以跨页面作为兜底。旧版错误提升为站点默认图标的文档缓存不再跨文档使用。
- 在 WebKit 隔离世界中观察和解码图标，不改写网页内容，不猜测正文中的 emoji，也不写死某个网站或星星图标。blob 图标只持久化图片，不持久化临时 blob 地址。
- 导航、图标更新和取消时验证文档及请求版本，避免旧的异步结果覆盖新图标。移除图标且站点兜底不存在时，重启也不会重新显示过期图标。

## 自动化验证

- 完整 `swift test`：应用测试 244 项／37 套件，MCP 共享层与 SDK 测试 8 项／3 套件。共 252 项，247 项通过，5 项原有密码事件循环场景按预期跳过，0 失败。
- favicon 相关 22 项测试覆盖缓存隔离、片段路由、旧缓存兼容、站点兜底、候选优先级、无效图标、移除及重启、取消竞争、blob 持久化，以及真实 WKWebView 和 BrowserTab 更新流程。
- WebKit 测试覆盖延迟更新、声明顺序、media、base 和 head 替换、iframe 忽略、单页路由、共享控制器解绑及网页脚本无法访问隔离世界。
- Python 本地测试页语法检查、Debug／Release 构建和 `git diff --check` 通过。

## 边界

仅使用网站发布的图标声明，不把正文任意图片或文档封面当作 favicon。损坏、不可读取或受跨域限制的图标会尝试其他声明及站点兜底。没有通过修改真实业务文档的图标来测试；动态变更和移除场景使用本地合成测试页验证。
