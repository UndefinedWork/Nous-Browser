# 1.0.2 验证记录

版本：1.0.2（Build 31），macOS 26、Apple Silicon。

- 完整测试：150 项执行通过、5 项预期跳过、0 失败，共 155 项；独立原生密码填写测试 10 项全部通过，无跳过，补齐上述场景。
- 强刷实测：本机长期缓存脚本初始为版本 1；源站更新到版本 2 后，普通 ⌘R 仍显示版本 1，⌘⇧R 显示版本 2。服务端记录 HTML 与脚本均收到 no-cache 请求，本地备注保留。
- 原生界面：⌘F、⌘G、⌘⇧G、重复聚焦全选、无匹配提示、Esc 关闭；实际滚动到匹配，查找框保留 ⌘← 文本移动。网页宽度 320pt 时查找栏完整可用。
- 缩放实测：⌘=、⌘+、⌘-、⌘0 使 CSS 视口依次从 657 变为 597、525、597、657。数字标签定位、Control-Tab 和反向循环切换通过。
- 新增缩放边界、选中页隔离、标签顺序、精确修饰键及查找异步结果隔离测试；11 种语言新增文案对齐。
- Release 构建通过；DMG 与 ZIP 的版本、实际 arm64 架构、严格签名、包内容及 SHA256 校验均通过。

原生功能验收使用隔离 Debug 构建和虚构本机页面；Release 安装包另行验证。仍为未公证的 ad-hoc 签名，真实网站登录、Touch ID 与首次钥匙串许可不在本轮验证范围内。

完整快捷键与未实现入口见 [快捷键核对](KeyboardShortcuts.md)。
