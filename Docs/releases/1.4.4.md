# Nous Browser 1.4.4

## 中文

- **下载恢复正常**：「图片存储为」「视频存储为」「链接存储为」及网页下载此前一直没有反应（下载在等待一个永远不会到来的编号），现在都会弹出保存位置。
- **「存储为…」（整页）**：弹出保存面板；文件名以 .mhtml 结尾时保存为单个网页归档。
- **「检查」可用**：开发者工具不再是空白，能看到元素、样式、控制台。
- **修复闪退**：关闭开发者工具窗口后浏览器会闪退，已修复。
- 右键菜单中的「重新载入」可用。
- 右键菜单打开时，截图／录屏快捷键也能使用（菜单会先关闭）。
- 右键菜单中去掉了无效的「在无痕窗口中打开链接」。

## English

- **Downloads work again**: Save Image As, Save Video As, Save Link As and page downloads did nothing (each waited for a download id that never came); they now ask where to save.
- **Save As… (whole page)** shows a save panel; a name ending in .mhtml saves one web archive file.
- **Inspect works**: Developer Tools no longer opens blank.
- **Fixed a crash** after closing the Developer Tools window.
- Reload in the right-click menu works.
- Screenshot and recording shortcuts work while a right-click menu is open (the menu closes first).
- Removed the non-working "Open Link in Incognito Window".
