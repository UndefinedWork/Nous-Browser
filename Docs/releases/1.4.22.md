# Nous Browser 1.4.22

## 中文

- 截图和录屏缺少权限时，可以从提示直接打开 macOS 的「录屏与系统录音」设置。授权后回到浏览器，点「重试」继续选择范围。
- 从 Chrome 网上应用店安装扩展时，浏览器以 macOS 原生弹窗显示扩展名和请求的权限。移除扩展时，确认弹窗使用系统的移除按钮。

## English

- Screenshots and screen recordings now offer a direct link to macOS Screen & System Audio Recording settings when access is missing. After granting access, return to Nous and choose Try Again to resume selection.
- Installing a Chrome Web Store extension shows its name and requested permissions in a native macOS sheet. Removing an extension uses a native confirmation with a destructive Remove button.
