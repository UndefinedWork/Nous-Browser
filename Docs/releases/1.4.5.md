# Nous Browser 1.4.5

## 中文

- **自定义窗口圆角**：在「设置 → 外观」中用滑块调整浏览器窗口的圆角大小（0–40 pt，默认 28 pt），可一键恢复默认。全屏时始终为直角。

## English

- **Window corner radius**: set how round browser windows are in Settings → Appearance (0–40 pt, default 28 pt), with a button to restore the default. Full screen always uses square corners.
