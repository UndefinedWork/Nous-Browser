# Nous Browser 1.4.20

## 中文

- 按 ⇧⌘N 新建隐私窗口。所有隐私窗口关闭后，本次会话的网站数据会清除。隐私地址栏的四个默认网站图标支持离线显示。
- 在资料库中打开 Chrome Web Store，查看权限并安装扩展。在左上角加号菜单中使用已安装的扩展。依赖 Chrome 原生侧边面板的扩展仍有兼容性限制。
- 在设置中将 Nous 设为默认浏览器。搜索引擎新增 Yahoo、Brave Search、Ecosia、Qwant 和 Startpage。
- 截图编辑标签会紧跟来源标签，关闭后回到原网页。资料库的分类标签在圆角栏内滚动，搜索框更紧凑。
- 网页请求打开其他应用时，Nous 使用 macOS 原生确认弹窗。

## English

- Press ⇧⌘N to open a private window. Closing all private windows clears that session’s site data. The four default website icons in the private address bar also work offline.
- Open the Chrome Web Store from Library, review permissions, and install extensions. Use installed extensions from the sidebar’s + menu. Extensions that require Chrome’s native side panel still have compatibility limitations.
- Set Nous as the default browser in Settings. Search options now include Yahoo, Brave Search, Ecosia, Qwant, and Startpage.
- Screenshot editors open below their source tab and return you to it when closed. Library categories scroll inside a rounded bar alongside a smaller search field.
- Websites that open external apps now use a native macOS confirmation sheet.
