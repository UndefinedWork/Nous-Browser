# Nous Browser 1.4.1

## 中文

- **截图与录屏权限只需授予一次**：应用改用固定的本地证书签名，后续更新不再重复申请「屏幕与系统录音」权限（本次升级后需再授权一次）。
- **网站登录弹窗**改为小型临时窗口，显示网站域名，完成后自动关闭，不再打开完整的浏览器窗口。
- **关闭窗口后标签仍在**：关闭最后一个窗口再从 Dock、⌘N、⌘T 打开，或退出后重新启动，都会恢复原来的标签。
- **右键菜单打开时**，截图和录屏快捷键也能使用。
- 截图与录屏完成后，编辑器在**当前窗口**新建标签打开。
- 起始页（没有选中标签）按 ⌘W 关闭窗口。
- 某些网页状态不再让「退出」无反应。
- 侧边栏「文件夹」统一改称**分组（Group）**。
- 后退／前进／刷新控件按设计稿调整尺寸与间距（展开 84×32，收起 32×88）。

## English

- **Grant screen recording once**: the app is signed with a stable local certificate, so updates keep the Screen Recording permission (grant it once more after this update).
- **Sign-in popups** open in a small transient window showing the site's domain, and close when done — no full browser window.
- **Tabs survive closing the window**: reopening from the Dock, ⌘N or ⌘T, or relaunching after Quit, brings back the last window's tabs.
- Screenshot and recording shortcuts work **while a context menu is open**.
- Capture editors open as a tab in the **current window**.
- ⌘W on the start page (no tab selected) closes the window.
- Quit no longer silently does nothing when a page can't answer the close request.
- Sidebar folders are now called **Groups**.
- Back, forward and reload follow the design's size and spacing (84×32 expanded, 32×88 compact).
