# Nous Browser 1.4.8

## 中文

- **AI 可以整理你的空间、分组和标签（MCP）**：在「设置 → AI 智能体」中开启后，Claude、ChatGPT 等本机智能体可以：
  - 一次读出完整结构（窗口 → 空间 → 固定区与标签列表 → 分组 → 标签）；
  - 用一段描述一次建好「空间 → 分组 → 标签」，例如「建一个『工作』空间，里面放『设计』和『研发』两个分组」。只会新增和整理，不会关闭任何标签；同名的空间、分组和相同网址的标签会被复用，重复执行也不会重复创建；
  - 新建、重命名、切换、排序空间；新建、重命名、换图标、展开收起、固定、解散分组；固定标签、把标签移入分组、移到其他空间或窗口、复制标签。
  - 删除空间、关闭分组会关闭标签，是单独的工具，需要先征得你的同意。

## English

- **Agents can organize your spaces, groups and tabs (MCP)**: with access turned on in Settings → AI Agents, local agents such as Claude or ChatGPT can:
  - read the whole structure (window → space → pinned area and tab list → group → tab);
  - build a space → group → tab structure from one description, e.g. "make a Work space with Design and Engineering groups". It only adds and rearranges, never closes tabs; spaces and groups with the same name and tabs with the same address are reused, so repeating it is safe;
  - create, rename, switch and reorder spaces; create, rename, re-icon, expand or collapse, pin and ungroup groups; pin tabs and move them into groups, other spaces or other windows, or duplicate them.
  - Deleting a space and closing a group close tabs, so they are separate tools that ask for your approval first.
