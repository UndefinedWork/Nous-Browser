# Nous Browser 1.4.25

- Added on-device text recognition (OCR) in the Screenshot Editor: press `X` or pick **Recognize Text** to detect text locally with Apple Vision, click individual lines or drag a marquee to select any region, and copy selected or all text with `⌘C`.
- Added a **Spotlight** region highlight tool (`S`) to focus attention on one or more areas with unified Light, Medium, or Dark backdrop dimming, and upgraded the **Highlight** marker to adapt automatically to dark and light backgrounds so highlighted text remains crisp.
- Added on-device **Screenshot Translation** and bilingual annotation overlays powered by Apple's Translation framework and NaturalLanguage (plus instant Simplified ↔ Traditional Chinese conversion): choose **Replace** for in-place translated screenshots or **Annotate** for bilingual callout cards, hold `Option` to compare with the original, and export translated images directly to PNG or the clipboard.
- Fixed website password saving so signing in now presents a native Save or Update Password prompt and remembers credentials reliably.
- Fixed a crash when clicking Autofill Save & Fill or address edit dialogs.
