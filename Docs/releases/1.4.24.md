# Nous Browser 1.4.24

- Replaced the webpage eyedropper with a native Liquid Glass color magnifier that tracks the cursor smoothly across displays, shows live sRGB hex and RGB values, supports scroll-wheel zoom and arrow-key fine nudging, and samples webpage pixels directly even without Screen Recording permission.
- Screen Capture now opens the macOS selection tool directly. Press Escape to cancel without seeing a permission alert.
- Screen Recording offers a shortcut to System Settings when macOS denies access. Other recording errors now show their own message.
- Refined the Library header by keeping horizontal scroll bars hidden and isolating the active download indicator.
- When upgrading from 1.4.23, macOS may ask for screen recording access once as it recognizes the new signing identity. Future releases check that identity against the previous version so existing permissions can carry forward.
