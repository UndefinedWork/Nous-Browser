# Nous Browser 1.4.9

## 中文

- **MCP 更容易连上**：
  - 修复了 Codex（ChatGPT 桌面版）等客户端有时无法与 Nous 建立连接的问题。
  - 智能体需要浏览器时，如果 Nous Browser 没有打开，会在后台自动打开，不再报「尚未连接」。
  - 出错时说明具体原因：浏览器未运行、AI 访问未开启，或正在启动。
- **一键接入**：「设置 → AI 智能体」里新增「连接到」，可以一键把 Nous 加到 Codex / ChatGPT 和 Claude，并显示是否已添加；Claude Code 可拷贝一行命令；其他应用仍可拷贝配置。

## English

- **MCP connects more easily**:
  - Fixed Codex (in the ChatGPT desktop app) and similar clients sometimes failing to connect to Nous.
  - If Nous Browser is not open when an agent needs it, it now opens in the background instead of reporting "not connected".
  - Errors say what is wrong: the browser is not running, agent access is off, or it is still starting.
- **One-click setup**: Settings → AI Agents has a new Connect section that adds Nous to Codex / ChatGPT and Claude with one click and shows whether each is set up; Claude Code gets a command to copy; other apps can still copy the configuration.
