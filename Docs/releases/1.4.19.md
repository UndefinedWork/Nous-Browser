# Nous Browser 1.4.19

- Fixed attachment and upload buttons failing to open the native file picker. File and folder selection now use Chromium’s standard chooser, including file type filters, multiple selection, and folder confirmation.
- Fixed stale website permission dialogs when switching tabs, while preserving Chromium’s site-specific permission settings.
- Fixed external application links becoming unresponsive after an earlier attempt or cancellation, and improved links that open a new tab or window.
- Empty auxiliary tabs now close after an approved external application launch, while the original page remains open.
