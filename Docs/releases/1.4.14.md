# Nous Browser 1.4.14

## 中文

- **“新建”菜单在 macOS 27 上显示图标**：macOS 27 默认会隐藏菜单项图标，现在 + 菜单及其“空间”子菜单的每一项都会保留图标。
- **菜单与 + 按钮之间留出间距**：“新建”菜单在 + 按钮下方约 6 点处打开，不再贴在一起。
- **空间圆点适应侧边栏宽度**：圆点只占用导航按钮和资料库按钮之间的空间，两侧各留 8 点；侧边栏变窄时依次显示 4、3、2 个圆点，放不下时隐藏，左右轻扫仍可到达每个空间。
- **当前空间的胶囊更短**：按设计稿改为 10×5 点。

## English

- **Add New menu icons on macOS 27**: macOS 27 hides menu item icons by default; every item in the + menu and its Spaces submenu now keeps its icon.
- **A gap under the + button**: the Add New menu opens about 6 points below the button instead of touching it.
- **Space dots fit the sidebar**: the dots use only the space between the navigation capsule and the Library button, 8 points clear of each. A narrower sidebar shows 4, then 3, then 2 dots, and none when they would not fit; swiping still reaches every space.
- **Shorter current-space capsule**: 10×5 points, as in the design.
