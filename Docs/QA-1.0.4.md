# 1.0.4 验证记录

版本：1.0.4（Build 33），Apple Silicon。

- 完整测试：187 项，182 项通过、5 项需要图形桌面环境的填写场景预期跳过、0 失败；独立原生密码填写测试 10 项全部通过，无跳过。
- 新增跨窗口迁移测试覆盖目标列表首项、中间、末项及越界落点，置顶与普通标签分组边界，目标原有标签对象和顺序保留，后台来源窗口路由及最后一个标签移出后的源窗口关闭。
- 活页面测试确认同一个 BrowserTab/WKWebView、DOM、未提交输入、页面缩放、前后退记录及网站数据存储保留；迁移后的标题、访问与密码候选回调归属目标窗口。旧源 Deck 的延迟更新不能抢回页面。
- 两侧会话和窗口 manifest 写入正确；迁移不会进入任一窗口的最近关闭标签记录。
- 标题测试覆盖选中标签、后台标签、页面异步修改 document.title、跨窗迁移与关闭后停止观察。原生 Window 菜单已实测显示 Browser Test 与 Scrollbar Test，而非两个相同的应用名称。
- 坐标测试覆盖 flipped/unflipped 视图、负窗口坐标、视图偏移及非零 bounds 原点的屏幕坐标往返。
- 已删除 Navigate 菜单中显式添加的 Open in Safari 按钮与调用，并删除 11 种语言的未使用文案；所有语言与源词表均为 136 个键，格式、键集合及占位符校验通过。Debug 和 Release 构建通过；隔离测试版和正式安装版均经原生菜单核对，入口已移除。

原生跨窗验收通过：先从含 3 个标签的窗口拖出测试页面，源窗口保留另外 2 个标签；再将新独立窗口中的测试标签拖入另一窗口的列表中间。目标顺序为 Scrollbar Test、Browser Test、Target Two、Target Three，选中刚移入的 Browser Test，单标签源窗口关闭，窗口总数由 3 回到 2。未点击保存的输入内容保留，另一源窗口的标签顺序保持。来源侧栏为 243pt，目标侧栏为 280pt，页面成功承接到目标布局。

拖拽采用独立的非激活浮层，连续跟随真实手势坐标，源列表保留占位；目标列表按逻辑行插入位置让位并使用 Spring。落位的位移与宽度同时按阻尼弹簧收敛。窗口或标签关闭、取消拖动时清理浮层；目标带有模态 sheet 或地址浮层时不接受跨窗插入。

已安装到 `/Applications/Nous Browser.app` 并启动，运行文件与打包构建一致。升级前正常退出并备份，原有 2 个窗口共 16 个标签的身份、顺序、置顶、选中状态和侧边栏布局均恢复一致。Release 的 DMG/ZIP 版本、arm64 架构、严格签名、内容与 SHA256 校验通过，仍为未公证的 ad-hoc 签名。

真实网站登录、持续音视频播放、画中画和网页元素全屏迁移不在本轮实测范围内。
