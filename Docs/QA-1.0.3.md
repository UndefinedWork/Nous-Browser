# 1.0.3 验证记录

版本：1.0.3（Build 32），Apple Silicon。

- 完整测试：178 项，173 项通过、5 项需要图形桌面环境的填写场景预期跳过、0 失败；独立原生密码填写测试 10 项全部通过，无跳过。
- 网页右键菜单实测：首项为 Open in New Tab，打开后在来源标签下方插入；Open Link in New Window 创建独立窗口，来源窗口的标签不变。原生下载、复制、分享和服务菜单保留。
- 原生拖拽实测：列表内第一项移至第三项后顺序正确，窗口数不变；拖到同一窗口的网页区域取消移动；拖出顶部或右侧后移动到独立窗口，来源列表移除原标签。
- 页面状态：在未点击保存按钮的本机测试页面中，拖出后输入内容、滚动位置保留；最后一个标签再次拖出后，原空窗口关闭，输入内容仍保留。迁移后的前进、后退按钮可用。
- 针对实际发现的坐标回归修复并复测：拖拽结束采用手势落点经真实视图转换的屏幕坐标，不让滞后的全局鼠标位置把内部排序误判为拆窗。新增 flipped/unflipped 视图、负窗口坐标、视图偏移及非零 bounds 原点的映射测试。
- 自动测试覆盖同一个 BrowserTab/WKWebView 的迁移、DOM 和未提交内容、页面缩放与前后退记录、当前 owner 的标题回调、旧窗口延迟更新隔离、关闭空窗口以及会话持久化。
- 两条菜单文案在 11 种界面语言中与源词表对齐。
- Release 构建通过；DMG 与 ZIP 的版本为 1.0.3（32），实际架构为 arm64，严格签名、包内容及 SHA256 校验均通过。应用继续使用未公证的 ad-hoc 签名。
- 已安装到 `/Applications/Nous Browser.app` 并启动，运行文件与发布构建一致。正常退出后升级，原有 3 个窗口的标签身份、顺序、置顶状态、选中标签和侧边栏布局均恢复一致。

原生功能验收使用隔离 Debug 构建和虚构本机页面，不读取真实账号密码。网页元素全屏时暂不转移，需先退出网页全屏；持续音视频播放、画中画和真实网站登录不在本轮实测范围内。
