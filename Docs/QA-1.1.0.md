# 1.1.0 MCP 验证记录

版本：1.1.0（Build 40），Apple Silicon，macOS 26.0+。实测环境为 macOS 26.7.2。

## 实现范围

- 随应用打包 `NousBrowserMCP`，使用官方 Swift MCP SDK 0.12.1 提供 stdio 服务。版本和依赖固定在 `Package.resolved`，上游许可随包附带。
- 16 个工具覆盖窗口和标签管理、导航、顶层页面快照、元素点击／填写／按键、滚动和 PNG 截图。页面动作必须明确指定标签 ID，元素动作使用有效快照引用。
- 图形应用通过当前用户专用的 Unix socket 接收操作，目录权限 0700、socket 权限 0600；不监听网络端口。设置默认关闭，支持停止访问和复制实际安装路径生成的配置。设置文案覆盖现有 11 种语言。
- 关闭服务、客户端取消或断开连接会取消等待中的请求，旧快照引用失效；已经发生的网站操作不会撤销。请求有大小和时间限制，同一浏览器串行执行 agent 请求。
- 页面值不从输入控件中返回，不提供密码库、Cookie、文件读取、任意脚本或系统控制工具。DOM 内容和截图仍可能包含网页展示的私人信息，授权范围见 [MCP 使用说明](MCP.md)。

## 自动化与互通

- 完整 `swift test`：应用测试 229 项／35 套件，MCP 共享层和 SDK 测试 8 项／3 套件。共 237 项，232 项通过、5 项原有密码事件循环场景按预期跳过，0 失败。
- 新增撤销引用断言后，单独重跑对应快照测试，通过；其余产品代码未再改变。
- 独立官方 Python MCP SDK 1.30.0 启动打包的真实 stdio helper，与独立 QA 应用连接，协商 `2025-11-25`；全部 16 个工具完成实测。包含中文填写及事件、点击计数、按键、前后退、跳过缓存刷新、滚动、PNG 解码及真实宽度不超过 2000 像素、新标签插入、窗口选择和关闭清理。
- 负向测试覆盖过期元素引用、元素替换／遮挡、缺失或错误 ID、未知工具和参数、非 HTTP(S) URL、嵌入账号密码 URL、密码和文件字段、输入控件默认内容排除、页面脚本无法访问隔离世界的快照引用。
- 设置界面实际启用和关闭；关闭后独立客户端调用返回未连接错误。测试新增窗口和标签均清理，QA 原有标签保留。
- Release helper 的原始 stdio 检查验证 `2024-11-05`、`2025-03-26`、`2025-11-25` 协商、未知版本回退、未知方法、无效分页游标、取消未知请求、stdin EOF 正常退出及无多余 stdout 输出。对 SDK 的 malformed JSON 响应加了窄范围适配，确保无法解析请求时返回 JSON-RPC `id: null`。

复现脚本：`Tests/Fixtures/mcp_test_server.py`、`Tests/Support/mcp_client_smoke.py`、`Tests/Support/mcp_protocol_smoke.py`。GUI 工具实测只连接隔离 QA socket 和合成测试网页，没有用 agent 调用用户的业务网页。未逐个安装或配置各厂商的 AI 客户端。

## 当前限制

此版为本机 stdio MCP，不提供远程 HTTP 服务；只读取网页主文档，iframe、shadow DOM 内部、画布控件和原生对话框不在 DOM 工具覆盖范围。页面点击和键盘事件为合成事件，不承诺绕过浏览器的真实手势限制、验证码或网站认证。截图仅覆盖可见网页区域。当前访问控制按 macOS 用户和全局开关生效，不提供逐个 agent 的独立授权。
